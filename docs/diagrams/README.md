# docs/diagrams/

Architecture diagram source **and** the exported image. Keep both in sync —
the report embeds the PNG, but the source must be here so it can be edited.

|             File              |                 Purpose                  |
|-------------------------------|------------------------------------------|
| `WebGoat-Architecture.drawio` | Editable source (draw.io / diagrams.net) |
| `architecture.png`            | Export used in the report and the README |

The diagram must show every component, the data flows between them (with ports),
and the trust boundaries drawn as distinct regions: public internet, internal
container network, and the database.

Diagrams must be drawn by the team, not taken from the internet.
