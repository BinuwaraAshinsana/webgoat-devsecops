# docs/report/

Report drafts and the assembled final document.

- Hard limit: **1800–2500 words excluding appendices**
- Screenshots belong in an appendix (appendices do not count toward the limit)
- References in IEEE style

## Section budget

|               Section               | Words | Owner |
|-------------------------------------|------:|-------|
| Executive summary + system overview |   250 | M1    |
| Threat model & risk assessment      |   450 | M2    |
| Secure coding walkthrough           |   550 | M3    |
| CI/CD pipeline & gates              |   450 | M4    |
| Secrets management                  |   200 | M4    |
| Industry trends / case study        |   300 | M2    |
| Reflection                          |   150 | M2    |
| Contribution statement              |   100 | All   |
